## 🧰 Troubleshooting & FAQ

**Q: I downloaded the file, but nothing happens when I click it.** 
A: Make sure you extracted the `.zip` file first (see Installation Guide, Step 1).) Also, check if your antivirus is blocking it. Temporarily disable it, try again, then re-enable it. 

**Q: The subtitles are not showing up.** 
A: Check that your microphone or speakers are working (play a video or speak into the mic.)). Also, ensure you pressed the "Start" button. Try selecting a different input source in the settings. 

**Q: The translation seems wrong or slow.** 
A: Make sure you are connected to the internet. Also, in settings, try switching to "Accurate" mode for better results, or "Fast" mode if latency is an issue. 

**Q: Can I use this with Zoom, YouTube, or Netflix?** 
A: Yes. Choose "Speakers" as your audio input. Then, the subtitle bar will appear over any application you are using. Youcan drag it out of the way if needed.
